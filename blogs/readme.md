# Blogs

Reading lists of AWS blog posts and announcements for the re:Invent 2026 networking session. Each file covers one service. Entries are a table of publish date and linked title, newest first.

| File | Service | Contents |
|---|---|---|
| [awscloudwan.md](awscloudwan.md) | AWS Cloud WAN | 54 posts from the [Networking & Content Delivery blog](https://aws.amazon.com/blogs/networking-and-content-delivery/category/networking-content-delivery/aws-cloud-wan/). Covers service insertion, routing policy, SD-WAN and Direct Connect integration, 1:1 NAT, flow logs, and customer stories. |
| [directconnect.md](directconnect.md) | AWS Direct Connect | 68 posts from the [Direct Connect category](https://aws.amazon.com/blogs/networking-and-content-delivery/category/networking-content-delivery/aws-direct-connect/). Covers hybrid connectivity design, flat-rate pricing, AWS Interconnect (multicloud and last mile), BYOASN, encryption in transit, and monitoring. |
| [networkfirewall.md](networkfirewall.md) | AWS Network Firewall | 81 posts from the AWS Network Firewall category across several AWS blogs (Networking, Security, AWS News, Architecture, Public Sector and others). Covers inspection architectures, the firewall proxy, Transit Gateway integration, IPv6, and automated internet firewall. |
| [route53resolverfirewall.md](route53resolverfirewall.md) | Amazon Route 53 Resolver DNS Firewall | 36 items in two sections: 18 blog posts and 18 What's New announcements. Covers DNS-based threat blocking, partner threat feeds, and data exfiltration controls. |

Posts that cover more than one service appear in each relevant file.
